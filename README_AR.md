# المختبر المدرسي الذكي — حزمة نشر الموقع

هذه الحزمة جاهزة للنشر كموقع ثابت على Render.

## محتويات الحزمة
- `index.html`: واجهة الموقع العربية.
- `render.yaml`: إعداد Blueprint للنشر على Render.

## النشر على Render عبر GitHub
1. أنشئ مستودع GitHub جديداً باسم `school-lab-smart` (لا تستخدم مستودع منصة الأسهم).
2. ارفع محتويات هذا المجلد إلى جذر المستودع، بحيث يكون `index.html` في الجذر مباشرة.
3. افتح Render ثم اختر **New → Static Site**.
4. اربط حساب GitHub واختر المستودع `school-lab-smart`.
5. اختر الفرع `main`.
6. اجعل **Build Command** فارغاً، و**Publish Directory** = `.`.
7. اضغط **Create Static Site** وانتظر اكتمال النشر. سيعطيك Render رابطاً ينتهي بـ `onrender.com`.

يمكن أيضاً استخدام ملف `render.yaml` عند إنشاء Blueprint على Render.

## تنبيه مهم حول حفظ البيانات
النسخة الحالية تحفظ التحضيرات والمخزون والتجارب المضافة داخل تخزين المتصفح (`localStorage`). هذا يعني أن البيانات تبقى على المتصفح والجهاز نفسه، ولا تتزامن تلقائياً بين iPhone والكمبيوتر أو بين مستخدمين. استخدم زر النسخ الاحتياطي بانتظام. لمزامنة البيانات بين الأجهزة نحتاج في مرحلة لاحقة إلى قاعدة بيانات وخدمة خلفية مع صلاحيات دخول.

## ملاحظة المحتوى العلمي
التجارب الموجودة أمثلة تنظيمية أولية وليست حصرًا رسمياً لتجارب المنهج. يجب مطابقة التجارب والخطوات والكميات مع كتب وأدلة وزارة التعليم المعتمدة للعام 1448هـ قبل التنفيذ.
